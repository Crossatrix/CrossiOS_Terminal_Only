ls (lists files in current folder)
cd <path>
edit <path> (edits a file or if the file does not exist it creates a new one. the editing text ui will override thother things temporarily)
cp <from path> <to path>
mv <from path> <to path>
rm <path>
rmf <path> (removes folders)
upload <path> <filename (optional)> (opens a file upload window on the device)
zip <folder path> <zip name>
unzip <zip path> <extract path>
cls (clears console but leaves files.)
reset (clears everything including files but opens a warning first)
